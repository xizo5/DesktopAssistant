# 仅支持 Windows、采用真嵌入（SetParent 语义），接受 UAC 权限边界

需求是"把桌面窗口汇总到一个主窗口里并真实嵌入"。浏览器端因沙箱无法操作 OS 窗口，直接排除，本应用只做 Windows 桌面端，不考虑 macOS/Linux（真嵌入在各平台是完全不同的 API）。嵌入采用真·父窗口收编（SetParent 语义，即 Qt Window Container 路线），而非画面镜像或自动排列独立窗口。已知并接受的边界：以管理员权限运行的程序对普通权限的本应用不可见、收不进（Windows UIPI 硬规则），处理方式是在窗口列表中置灰提示，需要时用户手动以管理员身份重启本应用；本应用不做默认提权（避免每次启动弹 UAC）。

## Consequences

- UWP/部分现代应用的窗口可能收不进或行为异常，属于已知限制，不做兼容性承诺
- 个别程序有最小宽度限制，格子缩小于该值时内容会被裁剪，不强行规避
