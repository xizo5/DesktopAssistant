# 桌面助手 (Desktop Assistant)

把别的程序窗口**真实收编**进一个主窗口统一管理：格子永远填满、拖分隔条实时自适应、随时弹回桌面原样、退出时绝不关闭任何程序。

不是截图也不是录屏——是 `SetParent` 级别的真嵌入，收进来的程序照常运行、照常交互。

## 亮点

- **真嵌入**：第三方窗口真正变成主窗口里的一个格子，照常交互
- **填满式布局**：格子拼满整个可用区域；拖分隔条实时重排，或一键套用模板（左右各半 / 1大2小 / 田字格）
- **换位置**：右键格子标题条，和另一个格子整体互换（窗口跟着格子走）
- **藏托盘不闪现**：最小化改为收进系统托盘，收编的窗口跟着一起藏，不会被它们自己的程序"顶到前台"
- **无边框标题条**：应用名 + 工具条 + 窗口按钮合并成一行；拖动、双击最大化、边缘拉伸、Win+方向键贴靠都保留
- **自愈**：上次异常残留的"孤儿窗口"（蜷成一小块、动不了的那种）收编时自动修复
- **绝不关程序**：弹回桌面原位，退出时全部自动弹出还原
- **绿色便携**：配置存在程序旁的 JSON 文件，不碰注册表

## 运行

```powershell
cd E:\zuo\讨论\桌面助手
pip install -r requirements.txt   # 只需一次（PySide6）
python main.py                    # 想不显示黑窗口就用 pythonw main.py
```

仅支持 Windows 10/11。

## 打包成 exe（送给朋友）

双击项目里的 `build_exe.cmd`，它会自动：

1. 安装打包工具 PyInstaller（只需一次）
2. 把 `assets/logo.png` 转成多尺寸图标
3. 打出单个文件 `dist\DesktopAssistant.exe`——对方无需安装 Python，双击就能用

发朋友直接把这个 exe 发过去即可。两个小提醒：

- exe 没有数字签名，对方首次运行可能遇到 Windows 蓝色 SmartScreen 提示，点「更多信息 → 仍要运行」即可
- 建议对方把 exe 放在桌面或某个普通文件夹里再运行：配置会存在 exe 旁边（`desktop_assistant.json`），方便携带和备份

## 使用

1. 点标题条「＋ 收编窗口」，从列表里选一个正在运行的窗口
2. 继续收编：新窗口会切开你**最后点过**的格子（先点一下想切的格子再点收编；活动格子标题条上有青色侧标）
3. 拖格子之间的分隔条调整比例；用「模板」下拉一键套用 左右各半 / 1大2小 / 田字格
4. **换位置**：右键格子标题条 → 选「与某个格子互换」，两个格子（连窗口）整体对调
5. 每个格子右上角「⤴ 弹出」把窗口放回桌面原处；关闭主窗口 = 全部自动弹出还原
6. 点标题条右侧「─」＝ 收进系统托盘（不是真的最小化）：收编的窗口跟着一起藏，不会闪现；点托盘图标随时找回主窗口，托盘菜单里还有「弹出全部窗口」和「退出」
7. 窗口没有系统标题栏：拖标题条空白处移动，双击空白处最大化/还原，窗口四边可拉伸，Win+方向键贴靠照常
8. 布局和收编清单存在程序旁 `desktop_assistant.json`，下次启动自动恢复（没开着的程序会留空格子，点它可重新选择）

## 已知边界

- 以**管理员权限**运行的程序收不动（Windows 硬规则）：列表里已标灰。确有需要时，右键本工具选"以管理员身份运行"
- **UWP/系统应用**（计算器、设置等）大概率收不进，已标灰
- 个别自绘界面的程序可能显示异常；个别程序有最小宽度，格子缩太小会被裁掉
- 收进来的窗口不再出现在任务栏/Alt+Tab——这是"真嵌入"的正常表现
- 格子内被收编程序的右键菜单属于那个程序自己；本工具的右键菜单在格子标题条和空格子上
- 无边框窗口拿不到 Win11 鼠标悬停最大化按钮的"快照布局"弹层（自绘按钮的系统限制），Win+方向键贴靠不受影响

## 两个为什么

> **为什么"最小化"是藏到托盘**：收编进来的窗口是主窗口的子窗口（属于别的进程），系统原生最小化会把它们一起缩到屏幕外，不少程序会不停把自己往前台顶，导致主窗口反复闪现、任务栏点击也难恢复。改成托盘隐藏后这两个问题都不存在了。

> **为什么弹出前要"体检"**：嵌入会让外部窗口变成子窗口样式；如果上一次会话异常退出，它们会以"孤儿"状态残留在桌面上（蜷成一小块、拖不动）。收编时检测并修复这种状态，避免把坏样子记成还原目标、弹回去还是坏的。
